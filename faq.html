General

Sobre la plataforma y el proyecto

¿Qué es Match Sport Integración?

Es la plataforma desarrollada por ISM para digitalizar los procesos administrativos de una escuela deportiva: inscripciones, programación de clases, seguimiento del avance deportivo, noticias y gestión documental.

¿Qué institución utiliza la plataforma como piloto?

El SENA es la institución piloto del proyecto. A partir de su proceso de inscripción y sus necesidades administrativas se definieron los requerimientos funcionales del sistema.

¿En qué tecnología está construida la plataforma?

El sistema se desarrolla con PHP, HTML, CSS y MySQL, según las restricciones tecnológicas definidas en la Especificación de Requerimientos de Software (ERS) del proyecto.

¿Qué roles de usuario existen?

Tres roles: Admin (acceso total, carga de noticias), Profesor (programación de clases y avance deportivo) y Alumno (inscripción, perfil y consulta de su progreso).

Inscripciones

Sobre el registro y la inscripción a clases

¿Qué documentos debo cargar para inscribirme?

Documento de identidad, certificado de residencia, certificado médico, certificado de afiliación a EPS y dos fotos tipo carné. Si eres alumno antiguo, también el carné del año anterior.

¿Qué pasa si el aspirante es menor de edad?

El formulario solicita adicionalmente el nombre, el documento y el teléfono del acudiente. Sin esos datos, el sistema no permite completar el registro.

¿El sistema revisa que mis documentos sean correctos?

No. La plataforma permite cargar los archivos solicitados, pero no valida su contenido; esa revisión la realiza el personal administrativo de la escuela.

¿Puedo inscribirme si no hay cupo en la clase?

No. Si la clase o categoría seleccionada no tiene cupo disponible, el sistema muestra "Cupo no disponible" y no permite completar la inscripción a esa clase.

Seguridad y Datos

Sobre el manejo de tu información

¿Cómo se protege mi contraseña?

Las contraseñas se almacenan cifradas y nunca en texto plano. Todo el tráfico hacia la plataforma debe viajar cifrado.

¿Qué pasa si olvido mi contraseña o fallo varias veces al iniciar sesión?

Tras 5 intentos fallidos consecutivos, el sistema bloquea temporalmente el inicio de sesión durante 15 minutos, como medida de seguridad.

¿Quién puede ver mis documentos personales?

Solo tú y el rol Admin, encargado del seguimiento administrativo, pueden consultarlos. El acceso está controlado según el rol de cada usuario (RBAC).

¿Bajo qué normativa se tratan mis datos personales?

El tratamiento de datos personales se rige por la Ley 1581 de 2012 de Colombia. Más detalles en nuestros Términos y Condiciones.

¿A dónde escribo si tengo un problema con la plataforma?

¿Puedo actualizar mis datos o documentos después de inscribirme?
